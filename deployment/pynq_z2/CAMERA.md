# GC2093 单颗 USB 广角摄像头适配

`legacy`固定在`1f11b16`，保留原多相机版本；`main`在该历史基础上实现单摄像头方案，未改写历史。14路、48 kHz、240 mm阵列及采集/CNN/SRP RTL沿用原实现。摄像头接PYNQ-Z2的Linux USB主机，由ARM PS处理，不接PDM引脚，不使用其板载麦克风替代同步阵列。

## 2. 当前处理流程

同步阵列 → PS FFT/PHAT/GCC/SRP（可选PL插值累加）→ 候选波束 → PL Tiny CNN（或可选PS BandMLP研究后端）→ 音频事件 → 单相机可见性 → 相应时刻USB缓存图像 → 外部车辆检测器 → 原图锚点反投影 → spatial关联 → 保存照片与候选标注。

- 默认`layout=single`、`count=1`，只有`wide-0`，没有隐含下视相机。安装高度、yaw/pitch/roll和offset可调，默认值不是实测位姿。
- 声学仍搜索360°。视野外声源保留音频事件，输出`outside_camera_view`，不强配画面内车辆。遮挡、漏检、过期图像或缺证据保留未匹配/歧义。
- 多候选分差不足或同分时保留`ambiguous_direction`与方向列表，联合路由相机；部分候选在画面外时标记`partly_outside_camera_view`。不能因只拍到其中一辆车就确定鸣笛归属。输入/特征溢出或激活饱和输出`invalid_audio`，不触发可靠鸣笛事件。
- 使用实测K和Brown五参数或OpenCV fisheye四参数，统一在**原始分辨率JPEG坐标**中检测、标注、反投影。不将去畸变坐标混到原图；强畸变对视觉模型的影响需另测。
- 相机中心为`(offset_x,offset_y,height+offset_z)`，height是阵列离地高度。世界+x为0°、+y为正方位、+z向上；pitch向下，相机轴为右/下/前，roll按代码的右/下轴旋转定义。
- USB尺寸、FOURCC或报告FPS与请求不符即报错。spawn子进程读帧，主进程保留有界JPEG缓存，异常写入camera_health。
- 默认缓存8帧、采样间隔0.25 s，约1.75 s历史；持续取流与缓存采样分开。必须按窗口中点距决策时刻的实测延迟扩容。每帧上限8 MiB，默认JPEG缓存上界64 MiB，另有队列、解码和模型内存，需测峰值。
- USB时间戳为主机read中点，仍含未知设备/驱动缓冲；JPEG经过重新编码。曝光同步、接触点与完整位姿未验证前，即使只剩一个几何候选，部署服务仍输出ambiguous。橙框为声学兼容的可能声源，灰框仅为其他视觉车辆。

## 3. 合作者操作顺序

命令详见[相机工具](README.md#相机工具)。本轮未安装OpenCV、未下载车辆模型，工具也不会自动安装。

1. 记录Linux/PYNQ/Python/NumPy/OpenCV版本、USB VID/PID、V4L2格式和供电状况。若已有`v4l2-ctl`可用`--list-devices`及`--device /dev/video0 --list-formats-ext`，本仓库不安装它。优先使用稳定的`/dev/v4l/by-id/...`路径。
2. `python scripts/camera.py probe --output outputs/usb-probe`检查模式及host_sequence_rate；再与声学并行持续运行，统计掉帧、gap、skipped_windows、CPU与内存。设备报告30 FPS不等于持续30 FPS。
3. `collect`采集棋盘，覆盖边角、不同距离和倾斜姿态。内角点数、米制格边长按实物填写，保持对焦和传感器模式不变。
4. 评估Brown/fisheye拟合，不能由商品畸变百分数推断模型。至少15张非重复有效图像，每第五张留出；训练图须覆盖4×3网格至少10格。保存训练/留出RMS、来源哈希和剔除原因。
5. 在camera.calibration填生成JSON路径；设置实测height/yaw/pitch/roll/offset，以至少4组**独立实测**地面坐标/原图像素执行`check-ground`。额外检查边缘、不同距离和maximum_angle；默认误差限仅为工具设置，低RMS不证明整个视野可靠。
6. 更改分辨率、裁切、镜头、对焦或位姿后重做相应检查。无标定的FOV仅用于规划，`simulation_only`标定不能开启实时视觉。
7. 另行确定ARM可运行的车辆模型、SHA256与许可，验证强畸变图像中的车辆/模型车像素尺寸、召回、速度和内存。decoded YOLO适配不代表任意ONNX都兼容。
8. 最后做带时间记录的鸣笛触发、照片保存和候选标注联调。几何、视觉模型和鸣笛分类须分开评价；视野外事件、错配、歧义和误报也必须计入。

## 4. 本机验证与固定仿真

`prototype/profiles/gc2093_single.json`中的fisheye参数**人为构造，仅用于仿真**，不保证同时符合三种标称FOV；不能复制到实物作为标定。

```powershell
.\prototype\.venv\Scripts\python.exe -B prototype/simulate_surround.py --profile prototype/profiles/gc2093_single.json --output prototype/outputs/gc2093_single_v1
```
