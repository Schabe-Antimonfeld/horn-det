# 12 实验设计与评价指标

## 1. 必须做三组基线

```text
A. GCC-PHAT
B. SRP-PHAT
C. Horn-aware SRP
```

所有算法必须使用**同一批 matched samples** 比较。

先按原始录音及可获得的采集来源组划分训练、验证、测试集，再执行切窗、重采样和增强。同一录音的重叠窗口、增强版本及仿真衍生样本只能属于一个划分；同一鸣笛事件的不同设备录音也需归入同一集合，避免只按片段或设备划分。来源信息不完整时明确记录限制。

Horn-aware 频率先验只从训练集统计，分类器权重及特征归一化统计只用训练集拟合；模型选择、前端参数、概率校准、噪声权重参数、PSR 映射及状态机门限在验证集确定后冻结，测试集只用于最终报告。使用预训练模型时另行记录权重来源、训练数据和冻结/微调范围。记录来源、划分、随机种子、几何参数和算法配置。仿真测试应包含未用于调参的声源/噪声录音及随机条件，区分公开录音分类（记录双声道处理策略）、仿真阵列定位和真实阵列结果。

本节三组为定位基线；鸣笛检测模型按第 07 章第 8 节的待确定实验计划另行比较，不混用两组 A/B/C 编号。比较分类器时保持相同数据划分和事件评价规则，并记录输入采样率、特征窗口、推理更新频率和门控配置。

## 2. 定位误差

对有有效定位输出的样本，真实角度 θ 与估计角度 θhat 的误差为：

$$
e_i
=
|\mathrm{wrap}(\hat\theta_i-\theta_i)|
$$

记全部应定位样本数为 N，有效输出样本集合为 V，数量为 Nvalid。平均绝对误差：

$$
MAE
=
\frac1{N_{valid}}\sum_{i\in V} e_i
$$

中位数：

$$
MedAE=\mathrm{median}(\{e_i:i\in V\})
$$

P90：

$$
P90=\mathrm{percentile}_{90}(\{e_i:i\in V\})
$$

成功率：

$$
SR_{10}
=
\frac{\#\{i\in V:e_i<10^\circ\}}N
$$

wrap 将角度差归一化到 [-180°, 180°)。同时报告总样本数、有效输出比例和无效数量；Nvalid=0 时 MAE、MedAE、P90 标为未定义。SR10 的分母采用全部应定位样本，无有效定位的样本计为失败，避免通过拒绝困难样本抬高成功率；N=0 时 SR10 也标为未定义。

## 3. 鸣笛检测

Precision：

$$
Precision=\frac{TP}{TP+FP}
$$

Recall：

$$
Recall=\frac{TP}{TP+FN}
$$

F1：

$$
F1
=
\frac{2TP}{2TP+FP+FN}
$$

分别报告窗口级和事件级指标，不将重叠窗口当作独立事件。事件级评价以进入 CONFIRMED 的预测事件为单位，并在测试前固定起始时间容差、必要的区间重叠条件及匹配规则。预测与标注一对一匹配：匹配成功为 TP，未匹配预测为 FP，未匹配标注为 FN；同一标注的重复预测计为 FP。分母为零时标为未定义并报告计数，不用任意数值替代。

实际监控还建议报告：

```text
False Positive / hour
```

误报率定义为未匹配的确认事件数除以有效连续监控时长（小时），并报告其中非鸣笛时长。由平衡的 1 秒分类片段不能推断真实监控误报/小时，需连续音频和事件标注。

## 4. 实时性

统计：

```text
FFT latency
GCC latency
SRP latency
Classifier latency (CNN baseline)
end-to-end candidate latency
end-to-end confirmed latency
```

使用同一单调时钟，并固定测量端点：

| 指标 | 起点 | 终点 |
|---|---|---|
| FFT latency | 本帧最后一个 PCM 采样被接收 | 本帧全部通道频谱可用 |
| GCC latency | 本帧全部通道频谱可用 | 所需 pair 的 GCC 可用，含互谱/PHAT/权重处理 |
| SRP latency | 所需 GCC 可用 | 方位、有效性和置信度可用，含搜索回退 |
| Classifier latency | 分类器输入特征完整可用 | 概率输出可用，含排队和设备间传输；CNN 为当前参考基线 |
| Candidate latency | 标注鸣笛起始采集时间 | 首条 CANDIDATE 消息输出 |
| Confirmed latency | 标注鸣笛起始采集时间 | 首条 CONFIRMED 消息输出 |
| Capture latency | 标注鸣笛起始采集时间 | 实际曝光时间，时钟需同步 |

组帧、Log-Mel 特征生成、上下文冷启动、状态平滑及跨分支等待均需计入对应端到端时间；并行分支的耗时不能直接相加。第 10 章协议 timestamp 是决策输入帧时间，不是消息输出时间，需另外记录输出时间。提前于标注起点的误匹配应单独核查，不能把负延迟解释为快速检测。

分别报告冷启动与稳态的均值、P90 和最大延迟；未检出事件不进入延迟统计，但必须报告漏检率及延迟统计事件数。持续处理还需报告帧输入/输出速率、缓冲峰值、丢帧数和回退比例，区分第 09 章理想吞吐估算、仿真周期和板上实测结果。

待确定分类器还需报告模型尺寸、乘加量、目标设备推理时间、短鸣召回率和量化误差。FFT 规则若作为前置门控，应评价完整链路，不能只在门控通过的片段上计算分类指标；PCEN、蒸馏和 CRNN 的独立对照要求以第 07 章为准。

## 7. 消融实验

Horn-aware SRP 应拆开：

```text
SRP-PHAT
SRP-PHAT + fixed horn band
SRP-PHAT + learned horn frequency weight
learned weight + spectral-subtraction retention weight
learned weight + noise PSD/SNR gate
learned weight + both noise weights
selected frequency configuration + pair pruning
```

对应第 08 章的独立频率权重消融，不将固定频带和学习权重默认叠加。搜索加速、剪枝和整数/分数延迟需单独比较；保持同一批样本和其他配置不变，并记录剪枝后的有效 pair 数。

每增加一个模块都记录：

```text
MAE
P90
success
latency
```

避免只给最终结果，无法证明改进来源。

## 8. 文献参考结果的正确使用

Furletov 在 car horn 实验中测试 10~80 m，并显示 sector-preselected SRP-PHAT 多数场景比单纯 GCC-PHAT 误差更低。

Hu 2026 的户外车辆实验显示动态剪枝 + 局部高分辨率定位能够在准确率、鲁棒性和计算量间获得更好平衡。

这些结果只能作为“方案合理性证据”。
